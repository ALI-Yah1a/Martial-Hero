FREE ANIMATED PIXEL UI SAMPLER - by Antahonist
==============================================

Free animations from six of my animated pixel-art UI kits, ready for any engine.

book/            Pixel Journal (brown cover): open, page turn, close
paper/           Animated Paper UI (parchment): scroll unroll + roll up, letter open
dialogue/        Animated Dialogue UI (parchment): box open / close, heart emote pop + loop, continue arrow,
                 parts/ = the dialogue box, name tag, choice box, portrait frame (+ nine_slice.json)
notifications/   Animated Notifications & Popups (parchment): achievement in / out, legendary item pop + glow loop,
                 level up
cards/           Animated Card UI (legendary unit card): flip, burn, cast + the static front and back
coupons/         Coupon Kit (glossy "dairy bogo" coupon): spawn, tear, burn strips + the coupon and a USED stamp

Each json clip folder has: frames/ (one PNG per frame), <clip>_sheet.png (all frames in a row), <clip>.json (frame
size, per-frame durations, loop flag, extra data such as the paper rect), <clip>.aseprite and a 2x preview GIF.
coupons/clips.json lists frame size, count and durations of the coupon strips.
