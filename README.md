# Martial Hero (first version)
- Martial Hero is a 2D platformer game with 5 levels. To complete all the levels you should complete the objectives to win each level!
- Try to kill the gorgons and collect the coins.
# IMPORTANT NOTE
- This is the first version of the game, it has some incomplete sections (e.g., levels), and there is still only 4 levels left.
- This week we finished the main menu, player scene, pickups, enemies, and 1 sample level. 
## How To Run The Game?
- To run the game you should open the itch.io link, then click the button "Run Game". So simple.
- This is the link: https://ali-yah1a.itch.io/martial-hero

## How To Play The Game?
- To play the game correctly, you should click the "New Adventure" button in the main menu after running the game. Then open the book and toggle in between the pages and choose the desired level.
- The only way to complete the level is by killing the required gorgons and collecting all the required coins.
- You must avoid the gorgons because they can attack you. If you got attacked 10 times successfully you will die.
  
## Controllers
- Movement is controlled using A and D or the ← and → arrow keys to move the character horizontally across the level.
- The player can jump using the spacebar or W button.
- There are three different attacks either by E or LMB or RMB.
- Using ESC for pause.
